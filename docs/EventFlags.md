# イベントのフラグと合成

`events.json` でフラグを使うときの書き方と注意点。ステップ・条件の全体の書式はここでは扱わない。

## フラグを書く・読む

フラグは「キー → 文字列」で、セーブにも入る。

| やりたいこと | 書き方 |
|---|---|
| 選んだ結果を書く | `choice` ステップ(選んだ `value` が入る) |
| 好きな値を書く | `setFlag` ステップ |
| イベントの発火条件にする | 条件 `{ "type": "flag", "key": "...", "value": "..." }` |
| 会話の途中で分岐する | `branch` ステップ(`flag` + `cases`) |

### `setFlag` ステップ

```json
{ "kind": "setFlag", "flag": "crafted", "value": "" }
```

- `flag`(キー)と `value` は必須。
- `value` を空文字にすると、フラグを空に戻す(未設定と同じ扱い)。

## フラグ条件のイベントは、フラグが変わった時点でも発火する

トリガーの中にいるときにフラグが変わると、その場で条件を見直して発火する。出入りし直す必要はない。

そのため、**条件のフラグが先に立っていると、他の条件が揃った瞬間にイベントが出てしまう**。前のイベントの冒頭で `setFlag` を使い、フラグを戻しておく。

## コードが立てるフラグ

| キー | 値 | 立つタイミング |
|---|---|---|
| `crafted` | `"1"` | 合成を1回でもして、合成画面を閉じたとき |

合成画面を開いたまま会話が始まると、会話側がパネルを閉じてしまうので、画面を閉じるまで待ってから立てる。立てる処理はコード側にあり、`events.json` からは変えられない。

## 例: 合成チュートリアル

合成させてから、合成後の会話を出す流れ(`events.json` の `5_item_combination_tutorial` と `6_item_combination_done`)。

1. イベント5 の冒頭で `crafted` を空に戻し、素材を `giveItem` で渡す。進行度は 5 になる。
2. イベント6 は、条件を「進行度 5」かつ「`crafted` が `1`」にする。プレイヤーが合成して画面を閉じると発火する。

```json
"conditions": [
  { "type": "progress", "value": 5 },
  { "type": "flag", "key": "crafted", "value": "1" }
]
```

イベント6 は部屋全体を覆う大きめのトリガーに置く(合成中にトリガーの外へ出ていると、画面を閉じても発火しない)。

## 合成装置の置き方

合成装置に近づくと「[E] 合成する」を出し、押すと合成画面を開く。

1. 装置の近くに、Is Trigger の Collider を持つ GameObject を置く。
2. `CraftStationInteractor` を付ける。文言は Inspector の `Label` で変えられる。

範囲に入る・出るの判定は扉(`DoorInteractor`)と同じ作りで、移動中(Field)かつ会話中でないときだけ操作できる。
